# [기능] 근거 페이지 — 제외 행 표와 excluded_rows.csv 내려받기

## 목적

- 제목 규칙: `[기능]` 근거 페이지(`tools/pages/evidence.html`)에서 집계가 제외한 행을 근거와 함께 보여 주고 CSV로 내려받게 한다
- 요구사항: `docs/team_plan.md` R3(제외 행 근거) — 무엇을 왜 뺐는지 기록이 남지 않던 한계를 없앤다

## 완료 기준

- ☐ 성공: 근거 페이지를 열면 `loadData()`의 `tally.excluded`로 제외 행 표(원본 행 번호·사유·원본 값)가 보이고, 행 수가 집계 페이지의 제외 행 수와 같다(S2)
- ☐ 성공: [excluded_rows.csv 내려받기]를 누르면 화면 표와 같은 행의 `excluded_rows.csv`가 받아진다(S3). 형식은 `docs/design.md` 2절(머리글 `원본행번호,사유,` + 원본 열 이름, UTF-8 BOM)
- ☐ 실패할 때: 집계 전(`tally`가 `null`)이면 "집계 페이지에서 먼저 붙여 넣으세요"를 보여 주고 CSV를 만들지 않는다
- ☐ 경계: 제외 행이 0개면 "제외된 행이 없습니다"를 보여 준다. 값에 쉼표·큰따옴표가 있어도 CSV가 깨지지 않는다. CSV를 다시 계산하지 않고 읽기만 한다
- ☐ 사유 옆에 "담당 검토 후 확정"이 보인다
- ☐ `tests/acceptance.md`의 AC2·AC3·AC6 통과

## 검증 방법

- `python tests/run_acceptance.py`에서 AC5·F1~F4 확인(미실행이면 미실행으로 쓴다)
- 화면 확인은 사람이 한다: 집계 페이지에서 표본을 집계한 뒤 근거 페이지의 표 행 수를 세고, 받은 CSV를 열어 화면 표와 대조한다
