# [기능] 뼈대와 통합 — 시작 페이지·공통 저장 함수·스타일

## 목적

- 제목 규칙: `[기능]` 시작 페이지·공통 파일 뼈대를 만들고, 마지막에 요약·백업·비우기로 통합한다
- 요구사항: `docs/team_plan.md` R2(시작 페이지 요약·백업·비우기)·공통(AC5) — 두 페이지가 같은 저장소 약속으로 만나게 하는 틀
- 두 단계로 나눈다: **뼈대 PR**(`Refs #번호`) → ②·③·④ 병합 뒤 **통합 PR**(`Closes #번호`)

## 완료 기준

- ☐ 뼈대: `tools/assets/common.js`에 `loadData`·`saveData`·`exportJson`·`importJson`·`clearData` 다섯 개가 `docs/design.md` 3절 그대로 있고, 키는 `team1_app` 하나만 쓴다
- ☐ 뼈대: `tools/index.html`에 메뉴(집계 페이지·근거 페이지 링크)가 있고, `style.css`에 공통 모양이 있다. 파일을 더블클릭해서도 열린다(외부 주소·`fetch`·`type="module"` 없음)
- ☐ 통합 성공: 집계 뒤 시작 페이지에 전체·제외·합계·판정과 "담당 검토 후 확정"이 보인다(S4)
- ☐ 통합 성공: [백업 내보내기]로 JSON 파일을 받고, [가져오기]로 되돌리고, [비우기]를 누르면 요약이 비워진다
- ☐ 실패할 때: 집계 전이면 "집계 페이지에서 먼저 붙여 넣으세요"를 보여 준다. 모양이 틀린 백업 파일은 오류를 알리고 저장하지 않는다
- ☐ 경계: 저장된 데이터가 없는 첫 방문, 제외 0건, 전부 제외(남은 0건)도 오류 없이 요약이 나온다
- ☐ `tests/acceptance.md`의 AC5·AC6·AC7(S4) 통과

## 검증 방법

- `python tests/run_acceptance.py`에서 F1~F4·AC5 확인 결과를 PR 본문에 붙인다(미실행은 미실행으로 쓴다)
- 화면 확인은 사람이 한다: 시작 페이지를 열어 요약·백업·가져오기·비우기를 눌러 본다

## 담당 파일

- `tools/index.html`, `tools/assets/common.js`, `tools/assets/style.css`, `README.md`, `docs/demo_script.md`

## 선행 이슈

- 뼈대 PR: 없음 (④와 함께 가장 먼저 병합)
- 통합 PR: #{2번 이슈}·#{3번 이슈}·#{4번 이슈} 병합 뒤

## PR 연결

- 뼈대 PR·1차 시험·README PR 본문 첫 줄은 `Refs #{이 이슈 번호}`, 통합 PR 본문 첫 줄은 `Closes #{이 이슈 번호}`를 씁니다.
