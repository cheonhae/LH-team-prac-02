# [검증] 표본 CSV·수용 기준표·파일 검사 설정

## 목적

- 제목 규칙: `[검증]` 가상 표본 CSV와 수용 기준표를 만들고 파일 검사 설정을 채운다
- 요구사항: `docs/team_plan.md` R1~R3 전체의 기준(S1~S4) — 웹앱이 낸 값을 기대값으로 옮기지 않고, 표본을 직접 열어 미리 정한다

## 완료 기준

- ☐ `data/team_sample.csv`(가상, UTF-8, 열 = 접수번호·접수일·유형·처리상태·내용요약)에 중복 행·빈칸 행·빈칸이면서 중복인 행을 일부러 넣었다. 실제 자료·실명·연락처는 없다
- ☐ `tests/acceptance.md` 2절 기대 결과(전체 행·제외 행과 행 번호·유형별·처리상태별 건수)를 표본을 직접 보고(엑셀 필터 등 두 번째 방법으로) 적었고, 근거 칸에 방법을 썼다
- ☐ `tests/acceptance.md` 3절 AC1~AC6에 S1~S4와 이어진 "하는 것·기대"를 적었다. S4는 AC7로 추가한다
- ☐ `tests/run_acceptance.py`의 `PAGES`(`tools/index.html`, `tools/pages/tally.html`, `tools/pages/evidence.html`)와 `STORAGE_KEY = "team1_app"`을 `docs/design.md`와 같게 채웠다. 검사 함수는 고치지 않는다
- ☐ 빈칸·중복 기준과 '전체 행' 정의에 대해 표본이 `docs/team_decisions.md`의 가정과 맞는지 확인하고, 다르면 결정 기록을 고친다
- ☐ 표본 사용 승인: ④ 팀원 B

## 검증 방법

- `python tests/run_acceptance.py`를 실행해 결과(통과·실패·미실행)를 PR 본문에 붙인다. 페이지 파일이 아직 없는 동안 F1·F3은 '미실행'이 정상이다
- 기대값은 사람이 표본을 보고 다시 센 값과 대조한다
