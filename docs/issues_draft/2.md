# [기능] 집계 페이지 — CSV 붙여 넣기·제외·건수표·합계 판정

## 목적

- 제목 규칙: `[기능]` 집계 페이지(`tools/pages/tally.html`)에서 붙여 넣은 민원대장 CSV를 제외 사유와 함께 걸러 건수표와 합계 일치 판정을 만든다
- 요구사항: `docs/team_plan.md` R1(붙여 넣기·제외)·R2(건수표·합계 판정) — 중복·빈칸 행을 눈으로 지우던 수작업을 대신한다

## 완료 기준

- ☐ 성공: 표본 CSV를 텍스트 칸에 붙여 넣고 [집계]를 누르면 같은 페이지에 전체 행·제외 행·합계, 유형별·처리상태별 건수표, "일치/불일치" 판정이 보인다. 값이 ④의 기대값과 같다(S1)
- ☐ 성공: 결과를 `docs/design.md` 2절 모양으로 `saveData`에 통째로 저장한다(`tally`)
- ☐ 규칙: 빈칸 = 접수번호·유형·처리상태 중 하나라도 비어 있음, 중복 = 모든 열 값이 앞 행과 같음(처음 나온 행은 남김), 둘 다이면 사유는 '빈칸'
- ☐ 실패할 때: 텍스트 칸이 비었거나 머리글에 접수번호·유형·처리상태 열이 없으면 이유를 화면에 알리고 저장하지 않는다
- ☐ 경계: 완전히 빈 줄 무시, 칸 수가 모자란 행은 빈칸 처리, 남은 행 0개면 0 = 0 = 0 "일치", 다시 집계하면 덮어쓴다
- ☐ 판정·사유 옆에 "담당 검토 후 확정"이 보인다
- ☐ `tests/acceptance.md`의 AC1·AC4·AC6 통과

## 검증 방법

- `python tests/run_acceptance.py`에서 AC5·F1~F4 확인(미실행이면 미실행으로 쓴다)
