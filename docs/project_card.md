# 프로젝트 카드 — 1조

> 팀 PRD ① 블록 첫 실습 · 조원이 말하고 드라이버 세션이 채워 커밋합니다(`[팀] 프로젝트 카드`). 인터뷰 전에 정하는 것이라 거칠어도 됩니다. PRD가 나오면 1·2절만 다시 맞춥니다.

## 1. 주제

- 출발점: 조원 PRD 메모(팀원 A의 docs/prd_memo.md)
- 한 줄: 민원 담당자가 · 주간 민원대장 CSV의 중복·빈칸 행을 손으로 거르고 건수를 세다 합계가 안 맞는 불편을 · 제외 행을 사유와 함께 걸러 유형별·처리상태별 건수를 세고 "합계 = 전체 행 − 제외 행"을 확인하는 여러 페이지 HTML 웹앱으로 줄인다
- 넣을 검증 절차: ☐ 근거 대조 ☑ 계산 검산 ☐ 정합 검사 (1개 이상)

## 2. 범위

| 오늘 만들 것 (MVP) | 오늘 만들지 않을 것 |
|---|---|
| 집계 페이지 — 유형별·처리상태별 건수표와 합계 일치 판정(합계 = 전체 행 − 제외 행) | 서버·로그인·DB |
| 제외 행·근거 페이지 — 원본행·사유·원본값 표, excluded_rows.csv 내려받기 | 실제 민원 자료(가상 표본만 사용) |
| | 차트 |
| | 보고서 문장 자동 작성 |
| | 대장 수정·정합 기능 |
| | 외부 라이브러리 |

## 3. 역할과 리뷰 짝

| 역할 | 이름 | 리뷰 짝 (이 사람의 PR을 승인) |
|---|---|---|
| ① 통합·화면 (PRD·Issue·범위 관리) | 팀원 A | 팀원 A (자기 리뷰) |
| ② 기능 A (집계 페이지) | 팀원 A (팀원 B에서 넘겨받음) | 팀원 A (자기 리뷰) |
| ③ 기능 B (근거 페이지) | 팀원 A | 팀원 A (자기 리뷰) |
| ④ 검증·데이터 (표본 CSV 준비·결과 대조) | 팀원 A (팀원 B에서 넘겨받음) | 팀원 A (자기 리뷰) |

- 조원이 2명이라 한 사람이 역할 두 개를 맡는다: 팀원 A = ①·③, 팀원 B = ②·④.
- 리뷰 짝 ①↔② · ③↔④를 그대로 두면 모든 PR을 다른 사람이 승인한다(A의 PR은 B가, B의 PR은 A가). 자기 PR 자기 승인·병합 금지는 그대로 지킨다.
- [변경 2026-11-24] 팀원 B가 개인 사정으로 빠져 1인 조가 되었다. 팀원 A가 ①~④를 모두 맡고, 리뷰 짝 대신 **자기 리뷰 후 병합**(`CLAUDE.md` 팀 규칙 1인 조 예외)을 쓴다. 범위는 줄이지 않는다.

- 표본 데이터 사용 승인: ④ (팀원 A — 2026-11-24 팀원 B에서 넘겨받음)
- PRD 범위 변경: 조원 합의(서기가 `docs/team_decisions.md`에 기록)
