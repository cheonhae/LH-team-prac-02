## 1. 무엇을 하는 도구인가

- 해결하는 업무 불편: 주간 민원대장 CSV에서 중복·빈칸 행을 눈으로 찾아 지우고 계산기로 합계를 맞추는 수작업이 매주 반복되고, 무엇을 왜 뺐는지 기록이 남지 않는다.
- 주 사용자: 매주 민원대장을 받아 건수를 집계해 보고하는 민원 담당 실무자(가상)
- 들어 있는 검증 절차: 계산 검산 — `전체 행 − 제외 행 = 유형별 합계 = 처리상태별 합계`이면 "일치", 아니면 "불일치"
- 출발점: 조원 PRD 메모(`docs/prd_memo.md`)

## 2. 사용법

### 여는 방법

- **배포 주소**: [https://cheonhae.github.io/LH-team-prac-02/tools/index.html](https://cheonhae.github.io/LH-team-prac-02/tools/index.html) 를 Edge 또는 Chrome으로 엽니다.

### 페이지 목록

| 페이지 | 파일 | 하는 일 |
|---|---|---|
| 시작 | `tools/index.html` | 메뉴 · 요약(전체·제외·합계·판정) · 백업 내보내기·가져오기 · 비우기 |
| 집계 | `tools/pages/tally.html` | CSV 붙여 넣기 → 중복·빈칸 제외 → 유형별·처리상태별 건수표 · 합계 판정 · 저장 |
| 근거 | `tools/pages/evidence.html` | 제외 행 표(원본 행 번호·사유·원본 값) · `excluded_rows.csv` 내려받기 |

### 쓰는 순서

1. 시작 페이지에서 '비우기'를 누릅니다(처음 쓸 때).
2. 메뉴로 집계·근거 페이지를 오갑니다.
3. 집계 페이지 텍스트 칸에 `data/team_sample.csv` 내용을 붙여 넣고 [집계] → 건수표·합계 판정이 보입니다. 근거 페이지에서 제외 행(원본 행 번호·사유·원본 값)을 보고 [excluded_rows.csv 내려받기]. 시작 페이지로 돌아오면 전체·제외·합계·판정 요약이 보입니다.
4. 처음부터 다시 쓰려면 시작 페이지 '비우기'. 데이터는 이 브라우저 안에만 저장되고, 백업은 JSON 파일로 내보냅니다.
